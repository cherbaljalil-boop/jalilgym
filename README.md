# Jalilgym

An offline-first Android training & nutrition coach — structured programs (PPL, Full Body, custom),
a fast workout logger with auto-progression, and goal-based calorie/macro plans with halal-aware food tagging.

- **Status:** specification phase — see the [Product & Architecture Blueprint](docs/BLUEPRINT.md).
- **Stack (planned):** Kotlin · Jetpack Compose (Material 3) · Hilt · Room · Proto DataStore · Health Connect
